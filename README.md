# HR Analytics

An end-to-end HR analytics project that explores employee data using *SQL, **Excel, **Power BI, and **Tableau*. The goal is to turn raw HR data into clear, actionable insights on workforce composition, attrition, performance, and compensation.

---

## Project Objectives

- Understand workforce demographics (age, gender, department, job role)
- Identify key drivers of employee attrition
- Analyze salary, tenure, and performance trends
- Build interactive dashboards that help HR teams make data-driven decisions

---

## Repository Structure

| File | Description |
|------|-------------|
| SQL project.sql | SQL queries for data cleaning, exploration, and analysis |
| PROJECT.xlsx | Project dataset / working file with cleaned data and analysis |
| Excel Dashboard.xlsx | Excel dashboard with pivot tables and charts |
| power bi Dashboard.pbix | Interactive Power BI dashboard |
| tableau Dashboard.twbx | Interactive Tableau dashboard (packaged workbook) |
| README.md | Project documentation |

---

## Tools & Technologies

- *SQL* – data extraction, cleaning, and aggregation
- *Microsoft Excel* – pivot tables, charts, and dashboard
- *Power BI* – interactive reporting with DAX measures
- *Tableau* – visual analytics and storytelling

---

## Key Metrics & Analysis

- Total employees and headcount by department
- Attrition rate (overall, by department, by job role, by age group)
- Gender and age distribution
- Average monthly income and salary hikes
- Years at company and tenure analysis
- Job satisfaction and work-life balance
- Overtime vs. attrition

## How to Use

1. *Clone the repository*
   bash
   git clone https://github.com/Rakshatham/Hr-Analytics
   
2. *SQL* – open SQL project.sql in MySQL Workbench, SQL Server, or your preferred SQL client and run the queries.
3. *Excel* – open Excel Dashboard.xlsx or PROJECT.xlsx in Microsoft Excel.
4. *Power BI* – open power bi Dashboard.pbix using Power BI Desktop.
5. *Tableau* – open tableau Dashboard.twbx using Tableau Desktop or Tableau Public.
